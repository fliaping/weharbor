# 首次使用：从登录微信到让助手读聊天

本页适用于 WeHarbor 0.1.0：WeChat 4.1.13.23、Selkies 2.0，数据分析为
`fliaping/WeChatDataAnalysis`（版本见 versions.lock.json）。分析页的具体按钮文字以实际界面为准。
首次启动与容器重启测试不能替代真实账号的密钥获取验证。
先按 [README](../README.md#本地构建与启动) 完成构建和启动，再从这里继续。

[English](first-run.en.md)

数据分析通过读取本机微信进程获取数据库密钥，再解密出只读副本供浏览和助手查询。
手机扫码登录、获取密钥、配置模型是三个独立步骤。

| 阶段 | 完成标志 |
| --- | --- |
| 打开工作区 | 浏览器中看到左侧导航和微信画面 |
| 登录微信 | 微信会话列表出现，本地账号数据已生成 |
| 获取密钥 | 分析页识别到账号并保存了经过校验的数据库密钥 |
| 浏览数据 | 在分析页打开一个会话能看到消息 |
| 配置模型 | Magpie 中添加了上游模型，助手可以选择模型 |
| 使用助手 | 助手能通过 MCP 读取少量消息 |

## 1. 打开工作区

在 Docker 主机上打开 `https://localhost:3001`，使用 `.env` 中的
`CUSTOM_USER` 和 `PASSWORD` 登录。首次使用自签名证书时，核对地址后继续。
在其他电脑访问可使用 SSH 隧道（`ssh -N -L 3001:127.0.0.1:3001 user@host`）
或 Tailscale Serve（`tailscale serve --bg --https=443 https+insecure://127.0.0.1:3001`，仅 tailnet 可见）。

左侧导航依次是 微信 / 分析 / 助手 / Magpie / 连接（Alt+1–5，macOS 用 Option）。
容器 healthy 只代表程序和桌面服务正常，不代表已经能读取聊天记录。

## 2. 登录微信

1. 在微信画面中用手机扫码（已有账号时点击“登录”），在手机上确认。
2. 等待会话列表和近期消息加载，打开一个熟悉的会话确认有文字消息。

能读取的是这个 Linux 微信实例已保存在本地的数据，手机上的全部历史不会自动出现。
容器重启后可能需要在手机上再次确认登录。

## 3. 在分析页获取数据库密钥

打开“分析”（Alt+2）。

- 已有该账号经过校验的 WeFlow 密钥时，分析页会直接复用，不需要附加到微信进程。
- 没有可用密钥时，在 Linux 数据源卡片中开始获取密钥，然后在 120 秒内
  在微信中**手动退出并重新登录**。获取过程只读微信进程内存；拿到的密钥会先用来
  解密校验，校验通过才保存。
- 图片密钥同样在分析页获取，并用本地图片校验。需要看聊天图片时再配置即可。

完成后打开一个会话，确认能看到消息。解密副本与密钥保存在
`/config/.local/share/weharbor/analysis`，权限仅限本人；原始加密文件不会被改写。

## 4. 配置模型

打开“Magpie”（Alt+4），添加上游模型提供方。Magpie 默认在本地对密钥、密码、
手机号、身份证、银行卡和邮箱做可逆脱敏后再请求模型。添加后约 15 秒，
模型会同步到助手的模型列表。

## 5. 使用助手

打开“助手”（Alt+3），选择模型后提问，例如“总结最近一天的群聊”。助手通过
本地 MCP 读取分析数据；发送消息等写操作需要先准备、再由你确认提交。
需要同时看微信时，点顶栏“并排”，或在微信画面下按 Alt+3 把助手放在右侧。

在其他 AI 工具中使用：MCP 地址为 `https://<你的主机>/workspace/mcp`，
Bearer Token 在 `/config/.config/weharbor/workspace.token`。详见 [工作区说明](workspace.md)。

## 常见问题

- 分析页提示没有可用密钥：确认微信已登录，再开始获取并在 120 秒内退出、重新登录微信。
  容器需要 `SYS_PTRACE`（Compose 已默认添加）。
- 获取超时或校验失败：重新开始一次；不要把密钥贴到日志、问题反馈或 Git 中。
- 助手里没有模型：先在 Magpie 中添加上游提供方，等待约 15 秒后刷新助手。
- 从仍带 Alpha 的旧版本升级：Alpha 已移除，原来的 Alpha API（5031 端口）、
  alpha-api skill 和 Alpha Token 不再使用；可从 `.env` 删除 `API_BIND_ADDRESS`、
  `API_PORT`、`AUTO_START_ALPHA`。数据目录中旧的 Alpha 文件可自行删除。
